# Project 3 — использование

## Что делает проект
Консольная программа (не веб-сервер), которая показывает, как создать собственный пакет и использовать его (Lesson 3). Пакет `math` содержит арифметические функции, а `main.go` их вызывает.

HTTP-запросов здесь нет: программа просто печатает результат и завершается.

## Запуск
```bash
cd project3-functions-packages
go run .
```
Вывод:
```
Mathematical Operations Demo
============================
10 + 5 = 15
10 - 5 = 5
10 * 5 = 50
10 / 5 = 2
Error: division by zero
```

Собрать исполняемый файл:
```bash
go build -o calc.exe .
./calc.exe
```

## API пакета `math`

| Функция | Сигнатура | Описание |
|---------|-----------|----------|
| `Add` | `func Add(a, b int) int` | сумма |
| `Subtract` | `func Subtract(a, b int) int` | разность |
| `Multiply` | `func Multiply(a, b int) int` | произведение |
| `Divide` | `func Divide(a, b int) (int, error)` | целочисленное деление; при `b == 0` возвращает ошибку |

Как поэкспериментировать: поменяйте числа в `main.go` или добавьте функцию в `math/operations.go`, например `Power`. Не забудьте, что её имя должно начинаться с заглавной буквы.

## Как это работает под капотом
1. **Модуль.** В `go.mod` объявлен модуль `project3-functions-packages`. Это корень путей импорта: пакет из папки `math/` импортируется как `"project3-functions-packages/math"`.
2. **Пакет = папка.** Все `.go`-файлы в `math/` начинаются с `package math` и составляют один пакет.
3. **Видимость.** Имя с заглавной буквы (`Add`) экспортируется, то есть доступно из других пакетов. Имя со строчной (`add`) видно только внутри `math`.
4. **Несколько возвращаемых значений.** `Divide` возвращает `(int, error)`. Это идиома Go: ошибка — обычное значение, а не исключение. Вызывающий код проверяет `if err != nil`.
5. **`errors.New("division by zero")`** создаёт значение ошибки. `fmt.Printf("%v", err)` выводит её текст.
6. **Конфликт имён.** Стандартная библиотека тоже содержит пакет `math`. Здесь конфликта нет, потому что в `main.go` импортирован только наш пакет. Если понадобятся оба, один из них нужно импортировать под другим именем: `stdmath "math"`.
7. `go run .` компилирует **все** пакеты модуля во временный исполняемый файл и запускает его.
