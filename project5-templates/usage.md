# Project 5 — использование

## Что делает проект
Мини-блог, страницы которого генерируются пакетом `html/template` (Lesson 5). Главная показывает список постов с кратким текстом, отдельная страница показывает пост целиком. Посты хранятся в срезе в коде.

## Запуск
```bash
cd project5-templates
go run .
```
Запускайте из папки проекта: шаблоны читаются из `./templates/`. Если запустить из другого места, программа сразу завершится с ошибкой `open templates/index.html`.

## Эндпоинты

| Метод | Путь | Ответ |
|-------|------|-------|
| GET | `/` | `200` HTML-список всех постов |
| GET | `/post?id=N` | `200` HTML-страница поста с ID `N` |
| GET | `/post?id=abc` или без `id` | `400 Invalid post ID` |
| GET | `/post?id=99` (нет такого поста) | `404 page not found` |
| GET | любой другой путь | `404 page not found` |

Доступные посты: `id=1`, `2`, `3`.

### Браузер
Откройте http://localhost:8080 и нажмите **Read more →** у любого поста.

### curl
```bash
curl http://localhost:8080/
curl "http://localhost:8080/post?id=2"
curl -i "http://localhost:8080/post?id=99"     # 404
curl -i "http://localhost:8080/post?id=abc"    # 400
```
Кавычки вокруг URL нужны, потому что `?` — специальный символ в shell.

## Как это работает под капотом
1. **Разбор шаблонов при старте.**
   ```go
   template.Must(template.New("index.html").Funcs(funcs).ParseFiles("templates/index.html"))
   ```
   - `Funcs(funcs)` регистрирует пользовательские функции. Это нужно сделать **до** разбора, иначе парсер не узнает их имена.
   - `template.Must` вызывает `panic`, если файл не найден или в шаблоне синтаксическая ошибка. Так ошибка видна сразу при запуске, а не при первом запросе.
   - Шаблоны разбираются один раз и переиспользуются. Это быстрее, чем разбирать файл при каждом запросе, и безопасно при параллельных запросах.
2. **Выполнение.** `indexTmpl.Execute(w, samplePosts)` подставляет данные и пишет HTML прямо в ответ. Внутри шаблона `.` («точка») — это переданные данные.
3. **Синтаксис шаблонов** (см. `templates/index.html`):
   - `{{range .}} ... {{end}}` — цикл по срезу; внутри цикла `.` — текущий пост;
   - `{{.Title}}` — поле структуры (оно должно быть экспортировано);
   - `{{if not .}}No posts yet.{{end}}` — условие;
   - `{{.Author | upper}}` — **конвейер**: значение передаётся в функцию `upper` (`strings.ToUpper`);
   - `{{excerpt .Content 50}}` — вызов функции с аргументами: первые 50 символов + `…`. Длина считается в символах (`[]rune`), а не в байтах, чтобы не разрезать кириллицу пополам.
4. **Параметры запроса.** `r.URL.Query().Get("id")` читает `?id=...`, `strconv.Atoi` превращает строку в число, `findPost` ищет пост в срезе.
5. **Автоэкранирование (защита от XSS).** `html/template`, в отличие от `text/template`, учитывает контекст: в HTML-тексте `<` превращается в `&lt;`, в атрибуте `href` значение URL-кодируется, в `<script>` — экранируется как JS. Если в пост попадёт `<script>`, он будет показан как текст.
